#  6 — Java

я лабораторна робота демонструє абстрактний клас та наслідування.

## пис задачі

отрібно створити загальний базовий клас для тварин і реалізувати різні підкласи з різною поведінкою.

## сновні елементи

- `PetAbstract` — абстрактний базовий клас.
- `Dog` — клас собаки з породою і звуком "Woof".
- `Cat` — клас кота з кольором і звуком "Meow".
- `MainLR6` — демонстрація роботи.

## Як запустити

```bash
javac -d out src/lr6/*.java
java -cp out lr6.MainLR6
```

```text
Pet [ID=1, Name=Rex, Age=3] [Dog: breed=Labrador]
```
