# ЛР 3 — Java

Цей проект містить виконання третьої лабораторної роботи на Java.

## Опис задачі

Потрібно реалізувати перевірку введених даних для об'єкта тварини:
- ім'я не може бути порожнім;
- вага має бути більшою за нуль;
- при некоректних даних використовуються власні винятки.

## Основні класи

- `InvalidPetDataException` — користувацький виняток для неправильних даних.
- `ValidatedPet` — клас, який перевіряє параметри об'єкта.
- `MainLR3` — головний клас для введення даних та обробки винятків.

## Як запустити

```bash
javac -d out src/lr1/*.java src/lr2/*.java src/lr3/*.java
java -cp out lr3.MainLR3
```
