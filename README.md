#  5 — Java

я лабораторна робота демонструє патерн Factory.

## пис задачі

отрібно створювати об'єкти тварин через окремий фабричний клас, замість прямого виклику конструктора в різних місцях програми.

## сновні елементи

- `PetFactory` — фабрика для створення тварин.
- `MainLR5` — демонстрація створення об'єкта через фабрику.

## Як запустити

```bash
javac -d out src/lr1/*.java src/lr5/*.java
java -cp out lr5.MainLR5
```

## риклад виведення

```text
Created via Factory: Pet[Name: Rex, Species: Dog, Age: 3 y.o., Weight: 14,50 kg]
```
